# DevOps

## What is DevOps?
A culture and set of practices that bring Development and Operations together to deliver software quickly, reliably, and continuously.

## Developer (Dev)
- Builds the application.

## Operations (Ops)
- Deploys, runs, maintains, monitors, and scales the application.

## Goals of DevOps
- **Automation** - of builds, testing, deployment, and infrastructure provisioning to reduce manual errors and speed up delivery.
- **Code quality** - enforced through practices like code reviews, static analysis, and consistent standards.
- **Continuous Integration (CI)** - merging code frequently with automated builds/tests to catch issues early.
- **Continuous Testing** - automated tests running at every stage of the pipeline, not just at the end.
- **Continuous Delivery/Deployment (CD)** - getting code to production quickly and reliably, often with minimal manual intervention.
- **Continuous Monitoring** - tracking application and infrastructure health in production to detect issues fast.
- **Faster time to market** - shortening the cycle from writing code to delivering value to users.
- **Collaboration between Dev and Ops** - breaking down silos so both teams share responsibility for reliability and delivery speed.
- **Reliability and stability** - through practices like infrastructure as code, rollback strategies, and incident response.
- **Feedback loops** - continuous feedback (from monitoring, testing, users) feeding back into development to improve quickly.
